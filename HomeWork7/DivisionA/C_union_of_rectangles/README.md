# C. Объединение прямоугольников

|                     |                                  |
|---------------------|----------------------------------|
| Ограничение времени | 2 секунды                        |
| Ограничение памяти  | 64Mb                             |
| Ввод                | стандартный ввод или input.txt   |
| Вывод               | стандартный вывод или output.txt |

На плоскости задано $N$ прямоугольников с вершинами в точках с целыми
координатами и сторонами, параллельными осям координат. Необходимо найти площадь
их объединения.


## Формат ввода:
В первой строке входного файла указано число $N$ ($0 ≤ N ≤ 1500$). В следующих
$N$ строках заданы по $4$ целых числа $x_1$, $y_1$, $x_2$, $y_2$ — сначала
координаты левого нижнего угла прямоугольника, потом правого верхнего
($0 ≤ x_1 ≤ x_2 ≤ 10^9$, $0 ≤ y_1 ≤ y_2 ≤ 10^9$). Обратите внимание, что
прямоугольники могут вырождаться в отрезки и даже в точки.


## Формат вывода:
В выходной файл выведите единственное число — ответ на задачу.


### Пример:
#### Ввод:
```
3
1 1 3 5
5 2 7 4
2 4 6 7
```
#### Вывод:
```
23
```
